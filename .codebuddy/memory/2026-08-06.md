## ReplyPilot：AI 记忆 → 店铺信息结构化表单

用户反馈「AI 记忆」一添加就报网络/接口错误，根因是自由文本（最多 500 字符）拼进 prompt 后总 token 过长，廉价模型（DeepSeek-V4-Flash）响应超时/截断 → JSON 解析失败。

改动（commit `59f37e5`）：
- `options.html`：删除 AI Memory textarea，改为 4 个短 input：店铺名称(30)/主营品类(50)/发货说明(30)/售后政策(40)
- `options.js`：ids 数组替换 `aiMemory` 为 4 字段；删除 `bindAiMemoryCounter()`
- `utils/storage.js`：`rp_aiMemory` → `rp_storeName/rp_storeCategory/rp_shippingInfo/rp_returnPolicy`
- `utils/parser.js`：新增 `buildStoreContext()`，从 4 字段拼成 ~80 字符结构化英文描述，删除 `MAX_MEMORY`；保留 `MAX_BODY`/`clampText`
- `services/ai-service.js`：两处 prompt 调用传入 4 字段
- `_locales` zh/en：删除 `optAiMemory*` 4 条，新增 `optStoreInfo/optStoreName/optStoreCategory/optShippingInfo/optReturnPolicy` 及 hint/placeholder
- `options.css`：删除 `.rp-char-count` 块
- 旧 storage key `rp_aiMemory` 已无代码引用（旧用户数据保留无害）

用户要求跨境店铺也能填支持配送的国家/地区。改动（commit `5a1e759`）：
- `options.html`：售后政策下方新增 `shippingRegions` input（maxlength=60），hint 移到该字段下
