Setup Guide

  1. Pick a provider Choose SiliconFlow, OpenAI, or Custom (OpenAI-compatible) in the AI Provider dropdown.
  2. API endpoint The API endpoint is auto-filled by the provider. Edit it only if you use a proxy.
  3. API Key Get your API Key from the provider console and paste it into the API Key field.
  4. Model ID Type the model ID, e.g. deepseek-ai/DeepSeek-V4-Flash or gpt-4o-mini.
