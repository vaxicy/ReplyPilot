=== 中文详细说明 ===

ReplyPilot 是一款为 Gmail 打造的 AI 智能邮件回复助手。打开任意 Gmail 邮件，在 ReplyPilot 浮窗里写一句指导（例如「帮我委婉拒绝，简洁即可」），或点一下关键词快速填入，AI 就会阅读邮件上下文并直接生成对应的回复草稿，一键插入 Gmail 回复框或复制到剪贴板。

核心功能：

- 指导式生成：用一句话告诉 AI 你想怎么回，点「生成回复」即可得到贴合要求的草稿，不再是千篇一律的模板。
- 关键词一键填入：内置常用关键词（专业、友好、轻松、简洁、温暖、正式、直接、热情、委婉拒绝、直接拒绝、询问更多信息、稍后跟进），点一下就填进指导框；浮窗内可随时增删，越用越顺手，拒绝也能从容又得体。
- 结束语与署名：结束语（如「Best regards」）与署名分开设置，格式规整；结束语可自定义，也可交给 AI 根据语境生成后再附加。
- 表达自然：回复符合真实人际沟通习惯，不生硬；支持自动跟随来信语言（中/英），也可锁定为指定语言输出。
- 个人上下文注入：可在设置「关于我」中填写你的身份、与收件人的关系、回复偏好等（AI 记忆），AI 生成回复时自动参考，让回复更贴合你的语气与身份。
- 多 AI 服务商支持：支持 SiliconFlow、OpenAI 以及任意 OpenAI 兼容接口，自定义 Base URL、API Key 与模型。
- 隐私安全：你的邮件内容仅用于生成回复，通过你自己的 API Key 发送至你配置的 AI 服务商。API Key 存储在本地 chrome.storage.local，不会上传至任何第三方服务器或用于模型训练。
- 浮窗交互：在 Gmail 页面内以可拖拽浮窗形式呈现，支持生成、重新生成、插入回复框、复制到剪贴板、清空等操作，无需离开邮箱页面。
- 双语界面：界面支持中文（简体）与英文，运行时即时切换。

安装后，打开任意 Gmail 邮件，点击右侧 ReplyPilot 图标即可开始使用。首次使用需在设置页配置 AI 服务商和 API Key。

你的反馈是我们持续改进的动力，欢迎在设置页反馈问题！

=== English Detailed Description ===

ReplyPilot is an AI-powered smart email reply assistant for Gmail. Open any Gmail message, type a one-line instruction in the ReplyPilot floating card (e.g. "politely decline, keep it short"), or tap a keyword to fill it in, and the AI reads the conversation context and drafts the matching reply — ready to insert into Gmail or copy with one click.

Key Features:

- Instruction-Driven: Tell the AI in one sentence how you want to reply and click "Generate Reply" — no more one-size-fits-all templates.
- One-Tap Keywords: Built-in keywords (Professional, Friendly, Casual, Short, Warm, Formal, Direct, Enthusiastic, politely decline, decline directly, ask for more info, follow up) fill the instruction box in one click. Add or remove them right in the card, so it gets handier the more you use it.
- Closing & Signature: Set the closing ("Best regards") and your signature separately, always formatted cleanly. The closing can be your own text or generated by the AI from context.
- Natural Phrasing: Replies read like genuine human correspondence (no machine-translation feel). Supports auto-detecting the incoming email's language (Chinese/English) or locking to a specific output language.
- Personal Context Injection: Fill in your role, relationship with the sender, and preferences in "About You" (AI Memory). The AI automatically incorporates these details so replies match your voice and identity.
- Multiple AI Providers: Supports SiliconFlow, OpenAI, and any OpenAI-compatible endpoint. Configure your own Base URL, API Key, and model.
- Privacy & Security: Email content is used solely for generating replies, sent via your own API key to your configured AI provider. Your API key is stored locally in chrome.storage.local — never uploaded to third-party servers or used for model training.
- Floating Card UI: Interacts directly within the Gmail page via a draggable, scrollable floating card. Generate, regenerate, insert into the reply box, copy to clipboard, and clear — all without leaving your inbox.
- Bilingual Interface: Supports Simplified Chinese and English UI, switchable at runtime.

After installation, open any Gmail email and click the ReplyPilot icon to get started. First-time users need to configure an AI provider and API Key in the Settings page.
